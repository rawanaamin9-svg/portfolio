# Rawan Amin — GitHub Pages

1. Create a public repository named rawan-portfolio.
2. Extract this ZIP. Upload index.html, assets and .nojekyll into the repository root. Do not upload the ZIP itself.
3. If the browser rejects the number of files, upload assets in batches, preserving the assets folder.
4. Open Settings > Pages > Deploy from a branch > main > / (root) > Save.
5. Wait for deployment and open the link shown under Pages.

Keep the assets folder beside index.html. The site contains 115 images, six MP4 videos, and a project PDF.
The visual editor downloads a revised index.html; upload that revised file to GitHub to publish edits.
